# The Tea Cozy

A landing page for a fictional tea shop in Portland, Maine. This was a Codecademy project on the Full-Stack Engineer path where you get a design mockup (it's in the `Specs` folder) and have to build the page to match it from scratch.

Live site: https://ktforge.github.io/Tea-Cozy/

The page has a fixed header with nav links that jump to each section, a mission banner, a "Tea of the Month" gallery, a locations section, and a footer. I used Flexbox for the layouts and a media query so the locations stack on smaller screens.

## Running it

Clone the repo and open `index.html` in your browser.
